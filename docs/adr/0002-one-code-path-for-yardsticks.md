# ADR-0002: 物差しは 1 本の計算で、2 値専用の計算を持たない

状態: 採用 (2026-11-20、0.2.0)

## 背景
0.2 は、0.1 が出した数を最後の桁まで保つ必要があります。
浮動小数点の値は演算の順で変わるので、3 値以上向けの式で 2 値を計算すると一致しないと考え、0.1 の計算を写した 2 値用と、softmax の多値用の 2 つを持つ案がありました。

## 決定
確率を、基準のクラス (0 番) 以外の値だけで持つ形 (reference form) にします。基準の値は常に残り (1 から和を引いた値) とします。
エントロピー、交差エントロピー、回帰の当てはめは、基準でない項を先に、基準の項を最後に足し、クラスごとに 1 回の積を取ります。
こうすると、基準でない値が 1 つのとき (2 値) に、0.1 と同じ演算を同じ順で行います。

## 理由
同じ数を 2 通りに計算する作りは、片方だけ直されて食い違います。
この形の試作は 0.1 の計算の写しと浮動小数点で完全に一致しました。設計の比較で 28 通り、別の読み手の試しで 160 通り、実装後のストレスの試しで 4,228 通りです。

## 捨てた案
- 0.1 の計算をそのまま写した 2 値用と多値用を並べ、クラスが 2 つのときに切り替える。同じことをする道が 2 つになります。
- 1 つの多値の式で、許容誤差の範囲の一致で済ませる。0.1 の数が保てません。

## 引き受けること
`src/yardsticks.py` を直すときは、演算の順を変えてはいけません。
`tests/golden/v01_metrics.py` (0.1 の計算の写しで、書き換えない) と完全一致で照らす検査が、これを守ります。

## 確かめ方
`tests/test_yardsticks.py`、`scripts/parity.py` による合成の例と FX の比較。
