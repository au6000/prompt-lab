# ADR-0007: 0.1 との互換は一回きりの移し替えで扱う

状態: 採用 (2026-11-20、0.2.0)

## 背景
0.1 の課題のフォルダには払った答えのキャッシュと、事前登録済みの研究があります。

## 決定
- 0.2 は 0.1 のフォルダを読まず、`plab migrate` を案内して断ります。
- `plab migrate` は移し替えの計画を表示し、`--write` で移し替えます。
- boolean と choice の答えは、損なわずに新しい記録へ移し、`via: "evaluate"` を付けます。
- score のキャッシュは `score/(n-1)` しか無いので移さず、理由を表示します。
- 事前登録済みの研究は `--unfreeze` のときだけ移します。評価の確かめ、推薦、選択、lock は `.plab/archive-v0.1/` に保管し、事前登録からやり直します。
- 0.1 のプロンプトのファイルは変えずにそのまま読めます。
- 名前を変えた記録の項目は、`scripts/renames_since_0.1.json` に理由つきで 1 か所に挙げます。

## 理由
2 つの形を読み続けると、どのコードにも形の分岐が残ります。
移し替えは事前登録の下で測る仕組みを変えることになるので、固定した研究は黙って移しません。

## 捨てた案
- 0.2 の中で、0.1 のフォルダとキャッシュを読み続ける。
- 固定した研究の移し替えを、一律に断る。キャッシュを 1 つ持つだけで移せなくなります。

## 引き受けること
0.1 の記録の置き場を読む外の道具は、動かなくなります。
`src/migrate.py` は、0.1 のフォルダが無くなったら消せます。

## 確かめ方
`tests/test_migrate.py`。FX のフォルダの写しで移し替えてから `scripts/parity.py` で比べ、0.1 の数が欠けも違いも 0 でした (2026-11-20)。
