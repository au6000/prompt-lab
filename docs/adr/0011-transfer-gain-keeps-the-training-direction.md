# ADR-0011: 評価と本番の組では、学習の組で覚えた向きのまま測る利得も出す

状態: 採用 (2026-11-22)

## 背景
`cv_gain_pct` は測る組の中で V を当て直すので、答えの向きを見ず、学習の組のあとで向きが逆になった答えも評価の組で高く出ます。
値の欄がある課題では、判断の表 (1,000 件あたりの値) が向きを見るので、選び方で落とせます。値の欄が無い課題で向きを見るのは AUC だけで、AUC は予想全体で 1 つの値です。
2026-11-21 に流した合成のチケットの課題 (値の欄なし) では、選ばれた案が、2024 年から向きが逆になる話題 (他社を検討中) を「解約しそう」の側に数えていました。評価の組では、強いもう 1 つの話題 (仕事が止まっている) が AUC を 0.558 に支え、`eval.auc > 0.5` の条件を通りました。

## 決定
評価と本番の組の記録に、向きを保った利得 `transfer_gain_pct` を足します。

1. 学習の組のすべての答えに V を当てはめ (`fit`)、切片を除いた係数で、行ごとに結果の各値の得点 E = B·x を作ります。
2. 測る組では E を固定し、切片と、0 以上の倍率 c だけを当てはめます。当てはめは `cv_gain_pct` と同じ分割の交差検証で行い、同じ割合を出します。
3. 0 の位置にも同じ量を足します。でたらめな答えの向きは、別のでたらめな答えに V を当てはめて作ります。ほかの物差しのでたらめな答えは、今までと同じ順で引きます。

選び方は `eval.transfer_gain_pct` と `eval.null_pct.transfer_gain_pct` を読めます。学習の組には無いので、`train.` で読む決まりは読み込むときに断ります。既定の選び方は変えません。

## 理由
- 向きが逆になれば c は 0 で止まり、利得は 0 の位置まで落ちます。効き目が弱まっただけなら c が縮むので、利得は正のまま残ります。
- 切片を当て直すので、組ごとに結果の割合が違っても点数は下がりません。
- 当てはめる数は答えの列の数によらず、定数の予測より c の 1 つだけ多くなります。列の数が違うプロンプトどうしを、`cv_gain_pct` より比べやすくなります。
- 予測器の形 (V の族) によらず、学習で覚えた形のまま当たるかを測れます。

合成の数 (答えは 1 列、学習と評価の組が各 3,000 件、5 回の平均) では次のようになりました。

| 評価の組での関係 | cv_gain | transfer_gain | c を 1 に固定した場合 | 何も当て直さない場合 |
|---|---|---|---|---|
| 学習の組と同じ | 6.79% | 6.79% | 6.80% | 6.68% |
| 効き目が半分 | 1.33% | 1.33% | −1.11% | −2.01% |
| 向きが逆 | 8.49% | −0.14% | −25.58% | −25.50% |
| 結果の割合だけが変わる | 6.66% | 6.66% | 6.82% | −1.73% |

チケットの課題で、記録してあった答えから計算し直した数は次のとおりです (machine の答え)。

| 案 | 評価の組 cv_gain | 評価の組 transfer_gain | 本番の組 transfer_gain |
|---|---|---|---|
| 選ばれた案 (仕事が止まっている、または他社を検討中) | 2.98% | 0.08% | −0.45% |
| 「仕事が止まっている」だけ | 2.37% | 2.37% | 0.98% |
| 「他社を検討中」だけ | 0.52% | −0.30% | −0.33% |

Jev が答えた選ばれた案は、評価の組で cv_gain 1.80%、transfer_gain −0.08% でした。

## 捨てた案
- 学習の組の V を、何も当て直さずに使う。結果の割合が変わるだけで負になります (上の表)。
- 切片だけを当て直し、c を 1 に固定する。効き目が半分になっただけで負になります (上の表)。
- c の符号を問わない。向きが逆の答えが、また点数になります。
- HSIC のような、形を問わない依存の物差しにする。単位がビットではなく、向きも形も見ないので、この問題を広げます。

## 引き受けること
- 評価と本番の組を測るときに、学習の組の答えも要ります。記録に無い答えは判定モデルに聞くので、費用がかかります。
- 評価と本番の組の 0 の位置は、記録してあっても一度だけ測り直します。学習の組の 0 の位置はそのまま使います。
- 0 の位置の中で上の方にあるかだけでは、罠が混ざった案を落とせません。チケットの課題の選ばれた案の 0.08% は、評価の組の 0 の位置の 98.5 パーセンタイルでした (0 の位置の真ん中は約 −0.34%)。「仕事が止まっている」の部分が、学習の向きのままでも少し当たるためです。罠を混ぜない案と差が出るのは、この量の大きさです。
- 結果が 3 つ以上の値を取るとき、c はすべての値に共通の 1 つです。値ごとに効き目の弱まり方が違うと、1 つの c では合わせきれず、その分だけ点数が下がります。

## 確かめ方
